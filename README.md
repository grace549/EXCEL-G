# Modulo Excel – Analisi Dati

## 📌 Descrizione
In questo modulo ho imparato a utilizzare Excel per l’analisi dei dati, con focus su formule, funzioni, gestione dei dataset, tabelle pivot e visualizzazioni.

## 📂 Contenuti del repository
I file sono organizzati per numero di esercizio e dal grado di difficoltà. Partendo da esercizi su formule di base poi funzioni logiche e di ricerca, gestione e pulizia dei dati, analisi con tabelle pivot e infine 
grafici e visualizzazioni.

## 🛠️ Tecnologie utilizzate
- Microsoft Excel
